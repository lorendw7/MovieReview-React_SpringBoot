# Movie Review Application

A full-stack movie review application built with MongoDB, Spring Boot, and React. Users can browse movies, watch trailers, and submit reviews. The backend and frontend are decoupled for independent development.

## Features

- **Browse Movies**: Display movies in a carousel with dynamic backgrounds and posters.
- **Watch Trailers**: Redirect to YouTube trailers via play buttons.
- **Submit Reviews**: Write and submit reviews for movies.
- **Responsive Design**: Optimized for both desktop and mobile views.

## Tech Stack

- **Frontend**: React, React Bootstrap, FontAwesome
- **Backend**: Java, Spring Boot, Spring Data MongoDB
- **Database**: MongoDB (local)
- **Build Tools**: Maven (backend), npm/yarn (frontend)
